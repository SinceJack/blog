用 GitHub Pages 搭一个足够简单的个人博客

如果博客的核心只是写文章，其实并不一定需要数据库和服务器。GitHub Pages 很适合个人博客、作品集和技术文档。

最简单的结构

一个静态博客最基本只需要一个 index.html 作为首页，再把文章放在 posts/ 目录里。样式可以直接写 CSS，也可以后续再拆成独立文件。

为什么适合个人使用

  • 不需要维护服务器和 PHP 环境
  • 每一次修改都有 Git 版本记录
  • 可以直接绑定自定义域名
  • 适合长期存档技术文章

等文章数量增多之后，也可以再升级到 Hexo、Hugo、Jekyll 或其他静态博客生成器，而不需要推翻整个站点。
