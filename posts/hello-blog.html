博客重新开张：从 yuanfei.fun 到 GitHub Pages

之前的 yuanfei.fun 已经停止运行，所以我决定重新搭一个更轻量的个人博客。

这次没有继续使用复杂的服务器环境，而是直接把博客放在 GitHub 上，通过 GitHub Pages 发布。这样做的好处很直接：维护成本低、版本记录清晰，而且博客内容本身也能和代码一样进行管理。

接下来会写什么

我会主要记录几个方向：教育科技、PHP 与 MySQL 项目开发、后台系统设计、AI 工具与工作流，以及一些真实项目里的问题和解决方案。

这个博客不会追求高频更新，更希望每篇内容都能留下一些真正可复用的经验。
